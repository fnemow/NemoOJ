# 前端 API 契约状态

更新时间：2026-09-21。

| 契约 | 状态 | 实现 |
|---|---|---|
| B01 公开题目 | 已实现 | 公开列表/详情强制 `isPublished=true`；详情只返回公开样例和资源限额 |
| B02 能力与模板 | 已实现 | `/question/languages` 返回题目版本、过期时间和实际运行时；`/question/code_template` 服务端生成模板 |
| B03 提交详情 | 已实现 | 本人/admin 按 ID 查询；“我的提交”由 Session 绑定；返回版本、稳定 verdict、运行时和实际限额 |
| B04 版本与幂等 | 已实现 | `problemVersion` 校验；`clientRequestId` + 快照 SHA-256；按 requestId 恢复；V7 唯一约束 |
| B05 管理工作流 | 已实现 | admin 详情、CAS 保存、预览、幂等发布、创建新版本草稿；发布版本评测字段只读 |
| B06 通用安全 | 已实现 | Long→字符串、ISO offset 时间、脱敏用户 DTO、`/inner/**` 网关阻断、生产同步 token CSRF |
| B07 逻辑题目生命周期 | 已实现 | 自然题号的当前版本指针；草稿发布、新版本原子切换、下线/重新上线及 CAS 冲突保护 |
| B08 用户反馈 | 已实现 | 登录用户创建和查看自己的反馈；管理员筛选、回复、处理中/已解决状态与 CAS 冲突保护 |

前端只调用 `/api/user/**` 与 `/api/question/**`，反馈接口位于 `/api/question/feedback/**`，不访问 judge、sandbox 或 inner 接口。写操作默认不重试；正式提交超时后先通过 `clientRequestId` 恢复。公开查询允许有界重试。

当前诊断字段只在后端存在安全、可公开的内容时返回；旧提交可能显示“未记录”。独立运行样例、自定义测试、云端草稿、比赛和讨论不属于首版。

上线步骤中必须先执行 V7、V9 和 V10。未应用迁移时，题目管理的 `rowVersion`、自然题号生命周期和反馈表不可用，服务不能作为本前端的生产后端。
