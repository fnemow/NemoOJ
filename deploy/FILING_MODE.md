# 备案期间的题库浏览模式

当前云端入口只展示题库、题目详情和公开样例，不提供登录或注册页面。
这是临时产品与部署配置，不表示对任何备案要求作合规认定。

## 开关与入口

- 前端构建使用 `VITE_SITE_MODE=filing npm run build`。认证页面不进入该构建；会话查询关闭，旧会话也不展示用户导航。
- 前端路由将认证及需登录的页面重定向到 `/problems`。
- Nginx 将 `/login`、`/register` 及其子路径重定向到题库，并拒绝入口上的登录、注册 API。
- 用户服务使用 `REGISTRATION_ENABLED=false`。该配置在生产环境默认关闭，即使绕过入口也不能注册；邀请码不会消耗。
- 已有用户、邀请码、提交及管理员数据保留。

首次 SSH 隧道仍使用回环地址 `127.0.0.1:18080`，浏览器来源必须与网关 `CORS_ALLOWED_ORIGINS` 中的端口一致。
另有 `127.0.0.1:18081` 的 API 验收入口，完全不提供 HTML；仅供 SSH 隧道或主机运维验证已有账号，注册始终拒绝。
两个端口均不能改绑 `0.0.0.0`。

## 验证

1. 浏览器打开题库，确认可查看题目且无登录、注册和用户管理入口。
2. 直接打开 `/login`、`/register`、`/admin/users`，确认回到题库。
3. 检查登录、注册 API 拒绝访问；在私有 API 入口检查用户服务的注册错误为 `40300`。
4. 构建产物中无 `LoginPage`、`RegisterPage`、`AuthLayout` 资源文件；`index.html` 使用 `no-cache`。

## 恢复

只有明确决定恢复后才执行：重新用 `VITE_SITE_MODE=normal` 构建前端，移除两个 Nginx 配置中的备案阻断规则，核对域名与 HTTPS 来源，然后按需设置 `REGISTRATION_ENABLED=true`。
开放后仍必须使用一次性邀请码。禁止为恢复注册而回滚到不验证邀请码的旧用户服务。
新站管理员初始化脚本调用注册接口，必须在关闭注册前完成初始化；脚本不会自动打开注册。
