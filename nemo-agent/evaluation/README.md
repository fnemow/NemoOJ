# NemoOJ Agent 评测入口

新增统一业务评测体系，详见 [BUSINESS_EVALUATION.md](BUSINESS_EVALUATION.md)。

- `business-v1.jsonl`：60 条原创业务样本，覆盖代码分析 20、私人题生成 12、学习计划 8、网站助手 12、反馈分流 4、题面维护 4；41 条回归、19 条留出。
- `python -m nemo_agent.evaluation`：数据校验、离线 Mock、显式付费模型组件评测、外部验收请求导出、记录评分和版本对比。
- 默认不调用模型、不连接生产数据库/队列、不发布题目；Mock 结果始终标为 `NOT_MEASURED`。
- 人工复核与沙箱证据缺失的结果保持待验证；不能用结构合法率冒充质量分。

## 原有私人题生成固定评测集

`private-generation-v1.json` 固定随机种子、18 种契约及每种 20 组合法输入，共 360 组。
其中十二种新契约覆盖字符串、动态规划、链表与二叉树的三个难度。
所有输入、参考算法和答案均由仓库中的平台代码产生，不包含用户提交或模型输出。
输入先经过契约校验；答案同时经过独立 Python 算法和后端性质校验。

评测分为两层，结果不要混合统计：

1. **固定候选层**：不调用模型，检查契约、编译、运行、六组合、独立算法、性质与隔离。
2. **真实生成层**：通过正常 VIP 接口提交目标，沿用模型调用账本、预算和任务租约。
   记录目录命中率、首次/最终通过率、耗时、输入/输出 token、模型调用次数和失败阶段。
   仅在任务所属的调用账本中累计成本，不能用沙箱耗时代替整体生成耗时。

目录之外的目标必须返回空模板选择，继续自由生成或明确说明无法支持，不能强行换题。
数据中的未匹配目标用于验证这一行为，并不意味着自由生成一定无法表示该目标。
升级评测输入或规则时新增数据集版本，保留旧证据；正常迭代不要重新随机生成基线。

Agent 回归命令（PowerShell）：

```powershell
$env:PYTHONPATH = "$PWD/nemo-agent"
./build/generation-venv/Scripts/python.exe -m pytest nemo-agent/tests -q
```

后端测试 `TrustedTemplateEvaluationTest` 从本固定数据集核验契约版本、参数类型、所有输入答案及非法输入。
云端固定候选脚本 `deploy/ops/trusted_templates_evaluation.py` 通过生产持久化验证队列运行十二种新模板，
不发布题目；终态后仅清理精确测试 UUID 对应的无用户、无模型账本和 Outbox 的合成元数据。
